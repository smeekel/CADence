# ADR 0011: lib3mf for 3MF (D-10) {#adr-0011}

- **Status:** Accepted (spec decision D-10)
- **Date:** 2026-11-11

## Context

Spec D-10 chooses lib3mf (BSD-2-Clause), the reference implementation of the 3MF specification, for 3MF export
(M-3DP-01) and validation; 3MF import is a *should* (M-IO-01).

## Decision

- lib3mf is added through vcpkg in step S2.09.4 and used only in `src/io/`. The rule 030 table and the
  `$ThirdParty` table in `scripts/check-layering.ps1` already allow it only in `io`.
- Tests validate exported files by reading them back with lib3mf (M-3DP-01c, S2.09.5).
- Import through lib3mf is added in S7.07.6.

## Consequences

- Units, build items, per-object colour and materials follow the reference implementation.

## Alternatives considered

- Writing 3MF by hand (zip plus XML): more code and no reference validation.

## Related requirements

D-10, M-3DP-01, M-IO-01; steps S2.09.4, S2.09.5, S7.07.6, S7.08.1.
