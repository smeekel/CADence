# Stage S3: Assemblies core {#stage-s3}

Checklist: `docs/IMPLEMENTATION_CHECKLIST.md`, section "Stage S3" (42 steps, S3.01.1 … S3.99.4).

## Exit criteria (spec section 9)

> Golden mechanisms show the expected DOF; an in-context part follows a changed reference part; interference detection finds the seeded clashes; exploded view and keyframe animation export frames.

Also, as for every stage: a runnable build, green tests and checks, updated traceability and docs (work package S3.99), and the owner's approval at S3.99.4.

## Key risks

- R-04: Mate solver performance on large or over-constrained assemblies; slow drag, wrong DOF counts (see `docs/RISKS.md`).
- R-07: Large-assembly memory and load time (see `docs/RISKS.md`).
