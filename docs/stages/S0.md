# Stage S0: Foundation {#stage-s0}

Checklist: `docs/IMPLEMENTATION_CHECKLIST.md`, section "Stage S0" (102 steps, S0.01.1 … S0.99.4).

## Goal

Turn the accepted scaffold into a working foundation: command bus, document model, open file format with F-09 magic, library scopes, kernel adapter, test harness, static checks, Qt shell with a 3D viewport and a headless CLI. Retire the toolchain and topological-naming risks with spikes SP-1 and SP-2.

## Entry criteria

- Scaffold accepted (`docs/planning-session/scaffold-report.md`): `scripts/build.ps1`, `scripts/test.ps1`, the three checks and `scripts/check-selftest.ps1` green.
- This plan approved by the owner.
- Known gaps: PowerShell 7 and LaTeX not installed (Doxygen 1.18.0 is installed and `scripts/docs.ps1` builds the HTML manual with no warnings; `-Pdf` needs LaTeX); hosted CI open (ADR 0033), so "CI runs all tests" is met by `scripts/ci-local.ps1` for now.
- P-03 static check scope decided by the owner (ADR 0026, Accepted): third-party network imports are allowed and summarised in `docs/network-imports.md`; network APIs in APP's own code fail.

## Exit criteria (spec section 9)

> `APP.slnx` builds from a clean clone in Visual Studio 2026. App launches with themed shell, dockable panels and a 3D viewport showing a kernel-generated box. A box command → save JSON → reload → save BSON → reload → export STL round-trips in an automated test, with F-09 magic checks. Global seed, user and project library folders resolve per F-10 (with an empty seed). CLI runs a command script headless. CI runs all tests.

Also, as for every stage: a runnable build, green tests and checks, updated traceability and docs (work package S0.99), and the owner's approval at S0.99.4.

- R-09: C++26 compiler support gaps (see `docs/RISKS.md`).
- R-10: Qt + vcpkg build times (see `docs/RISKS.md`).
- R-13: File-format evolution (see `docs/RISKS.md`).
- R-14: P-03 offline guarantee vs. third-party DLLs (see `docs/RISKS.md`).
- R-16: PowerShell 7 and LaTeX not installed (see `docs/RISKS.md`).
- R-17: No hosted CI yet (open decision) (see `docs/RISKS.md`).
- R-18: UI test environment (see `docs/RISKS.md`).
- R-23: Build-time network access (see `docs/RISKS.md`).
