# Stage S5: PCB layout {#stage-s5}

Checklist: `docs/IMPLEMENTATION_CHECKLIST.md`, section "Stage S5" (69 steps, S5.01.1 … S5.99.4).

## Goal

Deliver the integer-nanometre board database, layer stack and impedance, rules and DRC, placement, push-and-shove routing, high-speed routing, pours, HDI, and the 3D board model (built in `link`).
